   VIJETA WINGS — साइट कैसे चलानी है (बहुत सिंपल)
================================================================

हाँ भाई, ज़्यादा कुछ नहीं करना है। एक-एक चीज़ नीचे है:

📂 आपके पास 3 काम की चीज़ें हैं:
   1) index.html     ← यही वो साइट है जो browser में खुलती है
   2) images/        ← इसमें सारे poster/picture हैं
   3) dates.txt      ← competition की खत्म-तारीख़ इसमें लिखते हैं

बस इन तीनों को एक साथ रखो और index.html को browser (Chrome) में खोल दो —
साइट चालू हो जाएगी।

----------------------------------------------------------------
STEP 1 — साइट को अपने computer पर देखना (testing)
----------------------------------------------------------------
   · index.html पर double-click करो → Chrome में खुल जायेगी
   · पहली बार खुलने में 2-3 second लगेंगे (photos load हो रही होंगी)
   · बस!

----------------------------------------------------------------
STEP 2 — साइट को GitHub पर डालना (real website बनाना)
----------------------------------------------------------------
   · github.com पर जाओ, अपनी repo खोलो (जिसमें पहले भी code था)
   · नीचे दिए 3 चीज़ें drag-and-drop करो (या Add file → Upload):
       - index.html
       - images/   (पूरा folder चुनो)
       - dates.txt
   · "Commit changes" दबाओ → साइट live हो जाएगी
   · 30 सेकंड में दुनिया भर में दिखने लगेगी

----------------------------------------------------------------
STEP 3 — जब नई LIC competition आए (नया poster जोड़ना)
----------------------------------------------------------------
   · नई competition का poster photo Google/WhatsApp से download करो
   · उसका नाम बदलकर "newname.jpg" कर दो (हिन्दी/space मत रखो)
     जैसे: gana-picnic-2026.jpg
   · उस फाइल को images/ folder में डाल दो
   · index.html में poster वाली जगह पर इतना लिखो:

        <img src="images/newname.jpg" loading="lazy" decoding="async">

   · dates.txt में नीचे और एक line लिखो:

        newname.jpg = 2027-12-31

     (YYYY-MM-DD = year-month-date, जैसे 31 Dec 2027 = 2027-12-31)

   · GitHub पर upload कर दो → हो गया!

----------------------------------------------------------------
STEP 4 — competition की date पुरानी हो जाए तो?
----------------------------------------------------------------
   ऐसा कुछ नहीं करना! dates.txt में जो तारीख़ लिखी है, अगर वो आज से
   पुरानी हो जाए — तो automatically वो poster और वाला box साइट से
   गायब हो जाएगा (browser में दिखना बंद)।

   ख़ुद फाइल delete नहीं होगी computer/GitHub से — बस browser में
   दिखना बंद। अगर चाहो तो GitHub से hub से manually delete कर
   सकते हो बाद में।

----------------------------------------------------------------
⚠️ कुछ ज़रूरी बातें:
----------------------------------------------------------------
   · नाम में spaces मत रखो! "platinum dhamaka.jpg" गलत है,
     "platinum-dhamaka.jpg" सही है।
   · सिर्फ .jpg या .png file चलती है।
   · बड़ी फोटो (>2 MB) मत डालो — पहले phone की gallery से resize कर लो।
