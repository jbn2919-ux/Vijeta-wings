================================================================
   VIJETA WINGS — साइट कैसे चलानी है (बहुत सिंपल)
================================================================

📂 इस फोल्डर में क्या-क्या है:
   1) index.html              ← यही साइट है (browser में यही खुलती है)
   2) images/                 ← सारे poster / picture (i01.jpg … i17.jpg)
   3) dates.txt               ← हर poster की आखिरी तारीख़
   4) competitions/registry.json ← सफाई (cleanup) वाली list — छूना नहीं है
   5) scripts/cleanup.js      ← पुराने poster मिटाने वाली script (ज़रूरी नहीं, नीचे देखो)
   6) पढ़ें.txt                ← यही फाइल

----------------------------------------------------------------
STEP 1 — साइट को अपने computer पर देखना (testing)
----------------------------------------------------------------
   · index.html पर double-click करो → Chrome में खुल जाएगी
   · (computer पर देखने में dates.txt वाली auto-hide चीज़ काम नहीं करती,
     वह सिर्फ GitHub पर live साइट में चलती है — यह नॉर्मल है)

----------------------------------------------------------------
STEP 2 — साइट को GitHub पर डालना (deploy)
----------------------------------------------------------------
   · ज़िप को अपने computer पर Extract करो
   · github.com पर अपनी repo खोलो
   · Add file → Upload files पर जाओ
   · फोल्डर के अंदर की सारी चीज़ें (index.html, images, dates.txt,
     competitions, scripts, पढ़ें.txt) एक साथ drag-and-drop कर दो
     (पुरानी फाइलें अपने-आप नई से बदल जाएँगी)
   · "Commit changes" दबाओ → 30-60 सेकंड में साइट live हो जाएगी
   · अगर पुराना दिखे तो phone/Chrome में साइट को एक बार refresh करो

----------------------------------------------------------------
अभी साइट पर क्या दिखता है?
----------------------------------------------------------------
   अभी सिर्फ AGENT सेक्शन चालू है। DO / SBA / LICA, MARKETING OFFICIALS
   और CLIA — ये तीनों सेक्शन सिर्फ छुपे हैं, मिटे नहीं हैं। उनका सारा
   data, posters और rules फाइल में सुरक्षित है।

----------------------------------------------------------------
बाकी तीन सेक्शन दोबारा चालू करना (UNLOCK)
----------------------------------------------------------------
   सबसे आसान तरीका: index.html खोलो (GitHub पर फाइल खोलकर ✏️ pencil दबाओ),
   Ctrl+F से   VIJETA_ENABLED_ROLES   ढूँढो। वहाँ यह line मिलेगी:

        const VIJETA_ENABLED_ROLES=['agent'];

   इसे ऐसा कर दो (सब चालू करने के लिए):

        const VIJETA_ENABLED_ROLES=['agent','dos','marketing','clia'];

   या सिर्फ जो चाहिए वही जोड़ो, जैसे सिर्फ DO के लिए:  ['agent','dos']
        dos       = DO / SBA / LICA
        marketing = MARKETING OFFICIALS (BMO)
        clia      = CLIA / CO

   फिर "Commit changes" दबा दो। बस — posters के नाम बदलने की ज़रूरत नहीं।

----------------------------------------------------------------
नई competition / नया poster जोड़ना
----------------------------------------------------------------
   नई competition में poster के साथ-साथ data भरने वाले fields और
   milestone का हिसाब भी बनाना पड़ता है, इसलिए यह अकेले poster डालने से
   नहीं होगा। सबसे आसान तरीका:

   1) नया poster photo Claude को भेजो और लिख दो कि किस role के लिए है
      (जैसे "यह एजेंट की नई competition है, जोड़ दो")
   2) Claude नई ज़िप देगा (image, input fields, milestone सब जुड़ा हुआ)
   3) उसे ऊपर STEP 2 की तरह GitHub पर डाल दो

   नए poster की फाइल का नाम i18.jpg, i19.jpg … ऐसे ही आगे बढ़ता रहेगा
   (नाम में space या हिन्दी मत रखो; सिर्फ .jpg या .png; 2 MB से छोटी)।

----------------------------------------------------------------
competition की date पुरानी हो जाए तो?
----------------------------------------------------------------
   कुछ नहीं करना! आखिरी तारीख़ निकलते ही (अगले दिन से) वह competition,
   उसके data fields और poster साइट से अपने-आप गायब हो जाते हैं।
   फाइल GitHub में पड़ी रहती है; चाहो तो बाद में GitHub से delete कर दो।

   scripts/cleanup.js सिर्फ तब काम की है जब कोई इसे चलाए (जैसे GitHub Action
   से) — वह expire हुए posters की फाइलें हमेशा के लिए मिटा देती है। अगर
   आप इसे नहीं चलाते तो इसकी चिंता मत करो।
